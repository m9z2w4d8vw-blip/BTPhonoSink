4. Keep the working v8.0 .deb as a rollback.
5. Follow TESTING-v8.1.md exactly. Confirm the OFF-state baseline before

IMPORTANT: Potentially disruptive private bluetoothd initializer experiment.
OFF by default; enabling changes returned AVDTP count from 6 to 7 for the
NEXT daemon start ONLY. It does NOT register an A2DP Sink, publish SDP or
receive Windows Bluetooth audio. One-shot preference must be disarmed
successfully before the private getter returns modified data. If instability
occurs, keep the switch OFF and restart Bluetooth; restore v8.0 if needed.
